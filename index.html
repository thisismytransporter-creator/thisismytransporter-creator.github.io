Print Control

Private order-to-print software

Print Control is a self-hosted application used privately by its owner to run their own 3D printers. It reads order notification emails from the owner's own Gmail inbox, matches each order to a print file, schedules the print, and sends status alerts back to the same inbox.

It is not offered to the public and has no user accounts. It runs on a single privately owned computer.
